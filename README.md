# Water Sort - React Native (Expo Go)

This project runs the complete Water Sort puzzle game in React Native using Expo Go.

## How to run with Expo Go:

1. Open your terminal in this directory:
   ```bash
   cd "d:\vinod\water short\expo-app"
   ```

2. Install dependencies (if needed):
   ```bash
   npm install
   ```

3. Start the Expo development server:
   ```bash
   npx expo start
   ```

4. Scan the QR code shown in your terminal using the **Expo Go** app on your phone (Android/iOS).
